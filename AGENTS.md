# Project instructions

## GitHub transport

- Use SSH for all Git fetch and push operations in this repository.
- Keep `origin` set to `git@github.com:voropaevv/voropaevv.git`.
- Do not require GitHub CLI authentication for ordinary Git operations.
- A missing `gh auth` session is not a push blocker; verify the SSH remote and
  SSH connection before reporting any GitHub authentication problem.
- Use `gh` or the connected GitHub app only for API operations such as opening
  or managing pull requests.
