## Selected work

| Project | What it proves |
| --- | --- |
| [Jelluvi](https://github.com/voropaevv/local-ai-chat-exporter) | Open-source, local-first browser extension for exporting AI conversations to nine portable formats with no telemetry, no account, and no remote rendering |
| [Word Solver CV](https://github.com/voropaevv/words_solver_cv) | End-to-end iPhone → OpenCV/Tesseract OCR → prefix-pruned search → ranked results system, rebuilt with tests, Docker, and a bounded TCP protocol |
| [Automatic generation of neurocomics](https://doi.org/10.1109/ACDSA59508.2024.10467698) | First-author IEEE ACDSA 2024 research connecting real-time computer vision, narrative generation, and image generation |

## Engineering focus

- **Computer Vision:** detection, tracking, OCR, image processing, activity recognition
- **Multimodal AI:** turning video and structured perception data into generated narratives and visuals
- **Agent-directed engineering:** LLM-assisted research, implementation, testing, and automation with explicit verification
- **Product systems:** browser extensions, local-first workflows, reproducible tooling, privacy-conscious architecture

## Evidence, not just keywords

- Word Solver CV preserves a **123,509-word** dictionary and a documented **14-second** end-to-end run from its original environment
- Jelluvi supports **nine local export formats** and keeps conversation processing inside the browser
- The neurocomics pipeline was presented as a peer-reviewed **IEEE conference paper**
